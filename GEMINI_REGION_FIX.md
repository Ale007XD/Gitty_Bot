# Исправление ошибки "User location is not supported for the API use"

## Проблема
Google Gemini API имеет географические ограничения и может не работать в некоторых регионах.

Ошибка: `400 User location is not supported for the API use`

## Решения

### 1. Установка региона через переменную окружения

Добавьте переменную `GEMINI_REGION` в ваш `.env` файл или переменные окружения:

```bash
# Попробуйте разные регионы
GEMINI_REGION=us-central1        # США (по умолчанию)
GEMINI_REGION=europe-west1       # Европа  
GEMINI_REGION=asia-southeast1    # Азия
```

### 2. Обновление docker-compose.yml

Файл уже обновлен для поддержки новой переменной:

```yaml
environment:
  - GEMINI_REGION=${GEMINI_REGION:-us-central1}
```

### 3. Использование VPN

Если проблема не решается установкой региона, попробуйте:
- Используйте VPN с серверами в США или Европе
- Настройте прокси-сервер

### 4. Fallback режим

Бот теперь автоматически переключается в режим локальных ответов при ошибках геолокации:
- Показывает диаграммы аккордов
- Предоставляет базовую информацию о гитаре
- Работает с командами (/chords, /song, /parts, /exercises)

## Развертывание с новыми настройками

1. Создайте `.env` файл:
```bash
cp .env.example .env
# Отредактируйте .env и добавьте свои токены
```

2. Пересоберите и перезапустите контейнер:
```bash
docker compose down
docker compose build --no-cache
docker compose up -d
```

3. Проверьте логи:
```bash
docker compose logs -f gitti-bot
```

## Тестирование

После перезапуска отправьте сообщение боту. Если Gemini недоступен, бот покажет дружелюбное сообщение и предложит альтернативные команды.
